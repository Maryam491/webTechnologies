# Lab Task 2 - Express Application

This is a basic Express.js application converted from a static landing page.

## How to Run

1. Install dependencies:
   ```
   npm install
   ```

2. Start the server:
   ```
   npm start
   ```

3. Open your browser and go to `http://localhost:3000`

## Features

- Navigation links now route through Express.js
- Each navigation item leads to a separate page
- Static files (CSS, JS, images) are served correctly
- Responsive design maintained

## Routes

- `/` - Home page (original landing page)
- `/new-arrival` - New Arrival page
- `/sale` - Sale page
- `/lawn-2026` - Lawn 2026 page
- `/unstitched` - Unstitched page
- `/ready-to-wear` - Ready to Wear page
- `/men` - Men page
- `/ideas` - Ideas page
- `/home` - Home page
